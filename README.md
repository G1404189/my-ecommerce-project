# Be yoU Energy - E-Commerce Website

This is a fully functional front-end e-commerce platform built for a professional therapy practice specialising in Radiesthesia, Radionics, and TRG therapies in the United Kingdom.

## Project Structure
- **Pages/**: Contains all independent HTML templates (`index.html`, `products.html`, `cart.html`, etc.)
- **css/**: Central global stylesheet (`style.css`) managing responsive layouts.
- **js/**: Core client-side logic (`script.js`) handling cart DOM manipulation.
- **media/**: Optimised visual assets and product thumbnails.
- **evidence/**: Accessibility audit results (`Problem1.png` and `Fix1.png`).
- **README.md**: Project documentation and setup guide.

## Core Features
- **Dynamic Shopping Cart**: Full implementation of add, remove, and quantity updates via pure JavaScript DOM manipulation.
- **Localisation & Shipping Logic**: Auto-calculates weights and applies UK delivery thresholds in GBP (£).
- **Conditional Witness Form**: Toggles confidential intake fields based on selected therapy criteria.
- **100% Accessibility Conformance**: Audited via Google Chrome Lighthouse achieving full compliance.

## Instructions to Run the Project
1. Download or clone this project repository.
2. Open the root project folder in a code editor (e.g., Visual Studio Code).
3. Using the **Live Server** extension, launch the `index.html` file located within the `Pages/` directory.
4. Alternatively, open the `index.html` file directly in any modern web browser to execute locally.
